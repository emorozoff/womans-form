# womans-form

Анкета гостя — одностраничный опросник без сборки и зависимостей.

Всё живёт в `index.html`: три вопроса, по одному на экран, ответы никуда не отправляются
и остаются в браузере.

## Публикация

Settings → Pages → Source: Deploy from a branch → выбрать ветку и папку `/ (root)`.
Форма открывается по адресу https://emorozoff.github.io/womans-form
